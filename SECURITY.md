# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities **privately** using [GitHub's security advisory feature](https://github.com/demandcluster/ghostarchitect/security/advisories/new).

Do **not** open a public issue or pull request for security findings — public disclosure before a fix is in place puts users at risk.

We will acknowledge receipt within 72 hours and aim to resolve critical findings within 30 days.
